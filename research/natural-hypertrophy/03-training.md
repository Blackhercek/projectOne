# 03 · Тренировочная наука: все переменные с цифрами

> Каждая переменная разобрана по схеме: **что говорит наука → что делать → как проверить**.

---

## 3.1 Объём — главный дозируемый рычаг

### Что говорит наука

Самая крупная на сегодня работа — мета-регрессия **Pelland et al. (2025, Sports Medicine)**:
220 эффектов гипертрофии и 490 эффектов силы. **[A]**

Ключевые результаты:

- Зависимость «объём → гипертрофия» лучше всего описывается **корнем квадратным**:
  отдача положительная, но убывающая. Плато в пределах изученных объёмов **не достигается**.
- При среднем недельном объёме **12.25 дробных подхода** каждый дополнительный подход
  даёт **+0.24 % гипертрофии**.
- Для силы убывание отдачи выражено значительно сильнее, чем для гипертрофии.

Более ранняя работа Schoenfeld et al. (2017) дала градацию: <5 подходов/нед < 5–9 < 10+.

### Что это значит практически

«Больше — лучше, но всё менее выгодно, и упирается в восстановление и время».

| Недельный объём на мышцу | Кому | Комментарий |
|---|---|---|
| 4–6 подходов | Поддержание, перерывы, тяжёлые периоды в жизни | Сохраняет почти всё, не растит |
| 8–12 подходов | Новички, старт любого блока | Отличный старт-дефолт |
| **12–20 подходов** | **Основная рабочая зона** | Здесь живёт большинство результата |
| 20–25 подходов | Отстающие группы, опытные, короткие фазы | Требует безупречного сна и питания |
| > 25 подходов | Редко оправдано | Часто «мусорный объём»: качество подходов падает |

### Как считать подходы: дробный объём

Не все подходы одинаково «стоят» для конкретной мышцы. Рабочая эвристика **[C]**:

| Упражнение | Целевая мышца | Дробный вклад |
|---|---|---|
| Жим лёжа | Грудь 1.0 | Трицепс 0.5, передняя дельта 0.5 |
| Подтягивания | Широчайшие 1.0 | Бицепс 0.5, задняя дельта 0.3 |
| Приседания | Квадрицепс 1.0 | Ягодицы 0.5, бицепс бедра 0.25 |
| Румынская тяга | Бицепс бедра 1.0 | Ягодицы 0.75, разгибатели спины 0.5 |
| Жим гантелей сидя | Передняя дельта 1.0 | Трицепс 0.5 |
| Подъём на бицепс | Бицепс 1.0 | — |

**Типичная ошибка:** человек считает «12 подходов на бицепс» из изоляции и не учитывает
8 подходов тяг → фактически 16, и он недоумевает, почему локти болят.

### Как проверить

Раз в неделю заполните таблицу. Если не можете — вы не управляете главным рычагом.

| Мышца | Подходов/нед | Целевой диапазон | ОК? |
|---|---|---|---|
| Грудь | | 12–18 | |
| Спина (широчайшие) | | 12–20 | |
| Спина (трапеции/ромбовидные) | | 10–16 | |
| Передняя дельта | | 6–12 (много из жимов) | |
| Средняя дельта | | 12–20 | |
| Задняя дельта | | 10–16 | |
| Бицепс | | 10–16 | |
| Трицепс | | 10–16 | |
| Квадрицепс | | 12–18 | |
| Бицепс бедра | | 10–16 | |
| Ягодицы | | 8–16 | |
| Икры | | 10–16 | |
| Пресс | | 6–12 | |

> **Самая частая дыра у любителей:** задние дельты, бицепс бедра, икры — по 2–4 подхода
> в неделю, потому что они в конце тренировки и их «не хватает сил доделать».

## 3.2 Близость к отказу — второй по важности рычаг

### Что говорит наука

- **Refalo et al. (2023)**, систематический обзор с мета-анализом: нет доказательств,
  что тренинг **до** мышечного отказа превосходит тренинг **не до отказа** для гипертрофии. **[A]**
- **Robinson, Pelland et al. (2024)**, серия мета-регрессий, 55 исследований гипертрофии:
  зависимость положительная, но **выполаживающаяся** — ближе к отказу лучше, но выигрыш
  быстро уменьшается. Заметный провал стимула начинается, когда подход завершают
  **дальше 4–5 повторов от отказа**. **[A]**
- Прямые RCT (напр., 8 недель, тренированные): отказ и работа с RIR дают **сопоставимую** гипертрофию. **[B]**

### Что делать

| Тип упражнения | Целевой RIR | Логика |
|---|---|---|
| Тяжёлые многосуставные со свободным весом (присед, становая, жим) | **2–3** | Отказ здесь дорог: техника ломается, ЦНС садится, риск травмы |
| Многосуставные в тренажёре / на опоре | **1–2** | Безопасно, стимул высокий |
| Изоляция (бицепс, трицепс, дельты, икры, разгибания/сгибания ног) | **0–1** | Дёшево по восстановлению, отказ здесь оправдан |
| Последний подход упражнения | На 1 RIR ближе, чем предыдущие | «Финишер» без общей перегрузки |

### Как научиться оценивать RIR

Оценка RIR — навык, и новички систематически **переоценивают** свой запас
(думают «осталось 2», на деле 5). Калибровка:

1. Раз в 3–4 недели на изолирующем упражнении доведите один подход до **истинного отказа**
   (повтор не завершается, несмотря на максимальное усилие).
2. Сравните с ощущением «RIR 2» на предыдущем подходе. Обычно разрыв больше, чем казалось.
3. Маркер: если скорость последнего повтора **не замедлилась** заметно — вы были дальше 3–4 RIR.

> Практическое правило: **если вы никогда не доходите до отказа, вы, скорее всего,
> тренируетесь на 4–6 RIR и теряете значительную долю стимула.**

## 3.3 Частота — не самостоятельный фактор

### Что говорит наука

Pelland et al. (2025): **при равном недельном объёме частота не оказывает значимого
влияния на гипертрофию**. **[A]** Ранние данные Schoenfeld (2016) о превосходстве 2×/нед
над 1×/нед объясняются тем, что при одинаковом объёме за сессию 2× давало больший недельный объём.

### Что делать

Частота — это **инструмент распределения объёма**, а не отдельный стимул.

| Недельный объём на мышцу | Рекомендуемая частота | Почему |
|---|---|---|
| ≤ 10 подходов | 1–2× | Умещается в одну качественную сессию |
| 10–18 подходов | **2×** | 5–9 подходов за сессию — качество сохраняется |
| 18–25 подходов | 2–3× | Дальше 10 подходов за сессию качество падает |

**Практический предел за одну сессию: ~8–10 рабочих подходов на мышечную группу.**
Дальше усталость снижает силу и близость к отказу — подходы становятся «мусорными». **[B]**

Выбирайте частоту по расписанию и восстановлению, а не по «правильности».

## 3.4 Нагрузка и диапазон повторов

### Что говорит наука

**Schoenfeld et al. (2017)**, мета-анализ 21 исследования: гипертрофия при низких (≤60 % 1ПМ)
и высоких (>60 %) нагрузках **сопоставима**, при условии работы близко к отказу.
Сила при этом растёт значительно больше на тяжёлых нагрузках. **[A]**

Прямые данные: 10 недель тренинга до отказа на 30 % и 80 % 1ПМ дали почти идентичный
прирост объёма квадрицепса (6.8 % vs 7.2 %), но 1ПМ вырос значительно сильнее в группе 80 %.

Важная оговорка: **чем ниже нагрузка, тем критичнее подойти к отказу.** На 30 % 1ПМ
работа с RIR 3 практически не даёт стимула — слишком мало высокопороговых волокон рекрутируется.

### Что делать

| Диапазон | Доля объёма | Роль |
|---|---|---|
| 3–5 повторов | ~10 % | Сила, плотность костной ткани, «якорь» для прогрессии |
| **6–12 повторов** | **~55 %** | Основная рабочая зона: хороший баланс стимула и утомления |
| 12–20 повторов | ~30 % | Изоляция, суставосберегающие варианты, объём без ЦНС-нагрузки |
| 20–30 повторов | ~5 % | Икры, предплечья, дельты; только близко к отказу |

**Почему не всё в 5 повторах:** суставная и ЦНС-стоимость высока, объём набирать дорого.
**Почему не всё в 20:** дискомфорт и время; на практике люди не доходят до отказа.

Ключ: **распределение по диапазонам полезно, но второстепенно**. Один диапазон,
выполненный последовательно с прогрессией, побьёт «идеальное распределение» без прогрессии.

## 3.5 Амплитуда и длина мышцы — недооценённый рычаг

### Что говорит наука

- Мета-анализ Wolf et al. (2023): **удлинённые частичные повторы** (работа в растянутой части
  амплитуды) дают небольшое преимущество перед полной амплитудой (SMD ≈ −0.28 в пользу частичных). **[B]**
- Прямое RCT Wolf et al. (2025, *PeerJ*) на тренированных: **сопоставимые** адаптации
  у удлинённых частичных и полной амплитуды. **[B]**
- Систематический обзор 2025: тренинг на большей длине мышцы → тенденция к большему
  продольному росту (добавление саркомеров последовательно), эффект небольшой. **[B]**
- Региональная гипертрофия — **правило, а не исключение**: в 13 из 14 исследований рост
  по длине мышцы был неравномерным. **[A]**

### Что делать

1. **Полная амплитуда — дефолт.** Она безопасно накрывает и растянутую, и сокращённую позицию.
2. **Отдавайте предпочтение упражнениям, где нагрузка максимальна в растянутой позиции:**

| Мышца | Предпочтительно (нагрузка в растяжении) | Менее эффективно в одиночку |
|---|---|---|
| Грудь | Разводка/жим гантелей с глубокой амплитудой, кроссовер из верхнего блока | Сведение в тренажёре «пик-сокращение» |
| Широчайшие | Пуловер, тяга верхнего блока с полным растяжением | Тяга к поясу с коротким ходом |
| Бицепс | Сгибания на наклонной скамье, кроссовер за спиной | Концентрированные сгибания |
| Трицепс | Французский жим из-за головы, разгибания в наклоне из верхней точки | Разгибания у блока вниз |
| Квадрицепс | Приседания в полную амплитуду, гакк, сисси | Разгибания ног (пик в сокращении) |
| Бицепс бедра | Румынская тяга, сгибания лёжа с тазом в сгибании | Гиперэкстензия |
| Ягодицы | Выпады/сплит-присед с длинным шагом | Ягодичный мостик (пик в сокращении) |
| Икры | Подъёмы стоя с полным опусканием пятки, пауза внизу | Быстрые пружинящие повторы |
| Средняя дельта | Махи в кроссовере из-за спины | Махи гантелями стоя (пик сверху) |

3. **Удлинённые частичные — инструмент финиша.** Дошли до отказа в полной амплитуде →
   2–4 частичных повтора в нижней (растянутой) половине. Дёшево, эффективно. **[B]**
4. **Не жертвуйте амплитудой ради веса.** Половинный присед с +20 кг — это меньше стимула, а не больше.

## 3.6 Отдых между подходами

### Что говорит наука

- **Schoenfeld et al. (2016)**: 3 минуты отдыха дали значимо больший прирост силы и толщины
  мышц, чем 1 минута, за 8 недель. **[B]**
- **Байесовский мета-анализ (2024, Frontiers)**: преимущество отдыха **> 60 с** подтверждается;
  между диапазонами 1–2, 2–3 и 3+ минуты разница незначительна. **[A]**

Механизм: длинный отдых → больше ресинтеза фосфокреатина → выше усилие на следующем подходе →
больше механического напряжения суммарно.

### Что делать

| Упражнение | Отдых |
|---|---|
| Тяжёлые многосуставные (присед, тяга, жимы 5–8 повторов) | 2.5–4 мин |
| Средние многосуставные (8–12 повторов) | 2–3 мин |
| Изоляция | 1–2 мин |
| Суперсеты антагонистов (грудь/спина, бицепс/трицепс) | 1–1.5 мин между упражнениями |

**Экономия времени без потери стимула:** суперсеты **несвязанных** групп (жим + сгибания ног)
и «заполнение» отдыха растяжкой/мобилити. Суперсеты одной и той же группы — режут стимул.

## 3.7 Темп повторов

### Что говорит наука

Диапазон длительности повтора **0.5–8 секунд** даёт сопоставимую гипертрофию. Крайности
(взрывные баллистические повторы без контроля или сверхмедленные 10+ с) проигрывают. **[B]**

### Что делать

Простое правило: **2–1–1–0**

| Фаза | Секунд |
|---|---|
| Эксцентрика (опускание) | 2–3 |
| Пауза в растянутой позиции | 0–1 |
| Концентрика (подъём) | 1 (намеренно, но без рывка) |
| Пауза в сокращённой позиции | 0 |

Не считайте секунды вслух. Достаточно: **опускать контролируемо, поднимать с намерением,
не бросать вес и не отбивать.**

## 3.8 Подбор упражнений и вариативность

### Что говорит наука

- Систематический обзор (2022): **систематическая** вариация улучшает региональную гипертрофию;
  **избыточная случайная** вариация ухудшает результат. **[B]**
- Исследование 2024: различия в средней толщине мышцы между «варьируемыми» и «фиксированными»
  упражнениями — минимальны. **[B]**

Вывод: вариация — про **покрытие разных длин и векторов**, а не про «удивление мышцы».

### Что делать

**Правило 2–3 упражнений на крупную мышцу**, покрывающих разные позиции:

| Мышца | Упр. 1 (растянутая позиция) | Упр. 2 (средняя) | Упр. 3 (опц., другой вектор) |
|---|---|---|---|
| Грудь | Жим гантелей на наклонной | Жим штанги горизонтально | Кроссовер снизу вверх |
| Спина | Тяга верхнего блока / подтягивания | Тяга горизонтального блока | Пуловер |
| Квадрицепс | Приседания / гакк | Жим ногами | Разгибания ног |
| Задняя цепь | Румынская тяга | Сгибания ног лёжа | Гиперэкстензия / ягодичный мостик |
| Дельты | Жим над головой | Махи в стороны | Обратная разводка |
| Руки | Сгибания на наклонной / франц. жим | Сгибания молотом / разгибания у блока | — |

**Когда менять упражнения:**

- ✅ Когда прогресс остановился на 3+ недели при сохранённых питании и сне.
- ✅ Когда появился дискомфорт в суставе (меняем на схожий по вектору вариант).
- ✅ На стыке блоков (каждые 8–12 недель) — 1–2 упражнения, не всю программу.
- ❌ Каждую неделю «чтобы мышцы не привыкли». Мышцы не привыкают, привыкает нервная система —
  и именно эта адаптация позволяет вам поднимать больше. Вы её обнуляете.

## 3.9 Прогрессия — то, ради чего всё остальное

**Это самый практически важный подраздел документа.**

Объём и близость к отказу создают стимул. Прогрессия — это то, что заставляет стимул
**расти вместе с вами**. Без неё вы 5 лет делаете одну и ту же тренировку.

### Двойная прогрессия (рабочий дефолт)

Задаёте диапазон повторов, например **8–12**:

```
1. Берёте вес, с которым делаете 8 повторов при RIR 2.
2. Каждую тренировку пытаетесь добавить повтор в каждом подходе.
3. Как только ВСЕ рабочие подходы выполнены на верхней границе (12) —
   добавляете вес (+2.5 кг база / +1–2 кг изоляция) и возвращаетесь к 8.
```

Пример прогрессии жима лёжа:

| Неделя | Вес | Подходы × повторы | Действие |
|---|---|---|---|
| 1 | 60 кг | 9, 8, 8 | — |
| 2 | 60 кг | 10, 10, 9 | — |
| 3 | 60 кг | 12, 11, 10 | — |
| 4 | 60 кг | 12, 12, 12 | Верх диапазона достигнут |
| 5 | 62.5 кг | 9, 8, 8 | Вес добавлен, цикл заново |

### Иерархия прогрессии (когда вес больше не растёт)

Применяйте по порядку:

| # | Способ | Когда |
|---|---|---|
| 1 | +повтор при том же весе | Всегда первый выбор |
| 2 | +вес при сохранении повторов | Когда достигнут верх диапазона |
| 3 | +подход (объём) | Когда 1 и 2 встали на 2–3 недели |
| 4 | Улучшение качества: полнее амплитуда, чище техника, медленнее эксцентрика | Всегда фоном |
| 5 | −RIR (ближе к отказу) | Когда 1–3 исчерпаны, на 1–2 недели |
| 6 | +частота (перераспределить объём) | Когда объём за сессию превысил ~10 подходов |
| 7 | Смена упражнения | Последний вариант, после 3+ недель застоя |

### Реалистичные темпы прогрессии

| Упражнение | Новичок (в неделю) | Средний (в месяц) | Опытный (в квартал) |
|---|---|---|---|
| Присед, становая | +2.5–5 кг | +2.5–5 кг | +2.5–5 кг |
| Жим лёжа, жим стоя | +2.5 кг | +1.25–2.5 кг | +1.25–2.5 кг |
| Изоляция | +1–2 кг или +1–2 повтора | +1 повтор | +1 повтор |

Если ваши веса растут быстрее — прекрасно, но проверьте амплитуду и технику.
Если медленнее в течение 6+ недель — идите в [раздел 08](08-tracking.md#83-дерево-решений-еженедельный-аудит).

## 3.10 Техники интенсификации: дроп-сеты, rest-pause, myo-reps

### Что говорит наука

- Мета-анализ дроп-сетов (2023, *Sports Medicine Open*): гипертрофия **сопоставима**
  с традиционными подходами, но при **половине–трети затрат времени**. **[A]**
- Rest-pause vs традиционные подходы при уравненном объёме: **сопоставимые** прирост силы
  и толщины мышц. **[B]**

### Что делать

Воспринимайте эти техники как **инструмент экономии времени, а не как «супер-стимул»**.

| Техника | Как | Где применять |
|---|---|---|
| **Дроп-сет** | До отказа → сбросить 20–30 % веса → сразу ещё до отказа (1–2 сброса) | Последний подход изоляции |
| **Rest-pause / myo-reps** | Подход до RIR 0–1 → отдых 15–20 с → 3–5 повторов → повторить 2–3 раза | Изоляция, тренажёры, конец тренировки |
| **Частичные в растяжении** | После отказа — 2–4 повтора в нижней половине амплитуды | Любая изоляция |

**Ограничения:**
- Не более **1–2 таких подходов на мышцу за тренировку**.
- Никогда на приседе/становой со свободным весом.
- Не заменяют базовый объём: 6 подходов с дроп-сетами ≠ 14 обычных подходов.

## 3.11 Кардио и интерференция

### Что говорит наука

- Интерференция реальна, но **умеренна и ситуативна**. **[A]**
- **Бег вызывает значимо большую интерференцию для гипертрофии и силы, чем велосипед.** **[B]**
  Вероятная причина — эксцентрическая нагрузка и повреждение мышц при беге.
- Выполнение кардио **в той же сессии** после силовой даёт заметно больший негативный эффект
  у тренированных (ES ≈ −0.66). **[B]**
- Негативная корреляция с **частотой и длительностью** кардио: чем больше и чаще, тем сильнее помеха.

### Что делать

| Правило | Детали |
|---|---|
| Модальность | Велосипед, эллипс, гребля, ходьба под наклоном > бег |
| Разнесение | Разные дни или ≥ 6 часов между силовой и кардио |
| Порядок | Если в одной сессии — **сначала силовая**, кардио после |
| Дозировка на массонаборе | 2–3 сессии × 20–30 мин низкой интенсивности в неделю |
| HIIT | Максимум 1 сессия/нед, не в день ног и не накануне |
| Бытовая активность | 7–9 тыс. шагов/день — оптимум: здоровье без значимого «съедания» профицита |

**Зачем кардио вообще на массонаборе:** сердечно-сосудистое здоровье, улучшение
восстановления между подходами, лучший аппетит и контроль состава прироста.
Полностью убирать его — плохая идея по причинам, не связанным с мышцами.

## 3.12 Делоуды и периодизация

### Что говорит наука

Данные **смешанные**. **[B]**

- Часть исследований: делоуд-неделя не даёт прироста гипертрофии по сравнению с непрерывной работой.
- Есть данные, что регулярные плановые делоуды могут **замедлять** прирост силы (меньше суммарной работы).
- Обзор 2025 (*A Practical Approach to Deloading*) поддерживает **авторегуляцию**:
  делоуд по симптомам, а не по календарю.

### Что делать

**Не ставьте делоуд каждую 4-ю неделю «потому что так принято».** Ставьте по триггерам:

Делоуд нужен, если **два и более** признака держатся 5+ дней:

- [ ] Показатели в логе падают 2 тренировки подряд при неизменном питании
- [ ] Стойкая боль в суставах/сухожилиях (не мышечная крепатура)
- [ ] Сон ухудшился, утренний пульс повышен на 5+ уд/мин
- [ ] Нет желания идти в зал при обычно нормальной мотивации
- [ ] Разминочные веса ощущаются непривычно тяжёлыми

**Протокол делоуда (5–7 дней):**

| Параметр | Что делать |
|---|---|
| Объём | −40–50 % подходов |
| Нагрузка | 100 % от рабочей или −10 % |
| RIR | 3–4 (далеко от отказа) |
| Упражнения | Те же, техника чистая |
| Калории | Не снижать |
| Сон | Приоритет №1 |

**Периодизация:** на горизонте до 2 лет тренировочного стажа линейная прогрессия внутри
блоков работает не хуже сложных схем. **[B]** Простейшая рабочая модель:

```
Блок накопления (6–8 нед): объём растёт с 12 до 18–20 подходов/мышца/нед
  ↓
Триггерный делоуд (5–7 дней)
  ↓
Новый блок: небольшая смена 1–2 упражнений, объём снова с 12
```

## 3.13 Разминка: минимум, который окупается

| Этап | Время | Что |
|---|---|---|
| Общая | 3–5 мин | Велотренажёр/гребля до лёгкой испарины |
| Специальная | 5 мин | Первое упражнение: 50 % × 8, 70 % × 5, 85 % × 3, 92 % × 1 |
| Последующие упражнения | 1 подход | 1 разминочный подход с 60 % рабочего веса |

Статическая растяжка **перед** силовой временно снижает силу — переносите её на конец
тренировки или отдельное время. **[A]**
